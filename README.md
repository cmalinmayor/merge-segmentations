# compare-segmentations

[![CI](https://github.com/JaneliaSciComp/compare_segmentations/actions/workflows/ci.yaml/badge.svg)](https://github.com/JaneliaSciComp/compare_segmentations/actions/workflows/ci.yaml)
[![codecov](https://codecov.io/gh/JaneliaSciComp/compare_segmentations/branch/main/graph/badge.svg)](https://codecov.io/gh/JaneliaSciComp/compare_segmentations)

Small library for comparing and resolving multiple segmentations of the same i

## Installation

```bash
pip install git+https://github.com/JaneliaSciComp/compare_segmentations
```

## Development

This project uses [uv](https://docs.astral.sh/uv/) and
[just](https://just.systems). To set up a development environment:

```bash
git clone https://github.com/JaneliaSciComp/compare_segmentations
cd compare_segmentations
just install
```

See [CONTRIBUTING.md](https://github.com/JaneliaSciComp/compare_segmentations/blob/main/CONTRIBUTING.md)
for more, or run `just` to list all available recipes.
